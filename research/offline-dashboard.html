All protocols use exactly the same noisy sensory bits and cue in each episode. The feedback scheme has a reliable NACK control link and sends a second data packet only when necessary. The redundant feedforward control always transmits two copies. Message budgets are not matched.

What this can actually establish

Supported: A missing-data recovery mechanism can improve functional binding when transmission erasures occur. Shared inputs can generate strong observational correlations without an A→B causal link.

Not established: that feedback is uniquely necessary for binding; that workspaces necessarily outperform feedforward systems; or that any protocol possesses subjective experience.
